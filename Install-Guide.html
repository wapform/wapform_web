All accounts and passwords in this guide and in the sample configuration files are simulated (for example xyz / 123) and meant for local testing only. Replace them with your own before going live.

Turning on IIS: Control Panel > Programs > Turn Windows features on or off > Internet Information Services > World Wide Web Services > Application Development Features > check ISAPI Extensions.

3. Setup

  1. Run wapsetup.exe as administrator.
  2. Choose the setup type:
    • Full environment: Web, samples and Flutter (recommended)
    • Custom: pick the components yourself
  3. With the IIS module, confirm the IIS site (default Default Web Site) and application pool (default DefaultAppPool). Setup then enables 32-bit applications, allows the ISAPI extension, maps *.wml to C:\Wapform\WapServ.dll, adds index.wml as default document, grants write access to the license and upload folders, and restarts the pool. Log: C:\Wapform\setup\iis-setup.log.
  4. The sample store is placed both in C:\Wapform\shop (for WapForm Web Server) and in the shop folder of the IIS site (for IIS).

Running setup again (upgrade) never overwrites samples or wapform.ini you have changed; uninstalling keeps them too, unless you answer Yes to Remove everything as well?: then C:\Wapform (samples, wapform.ini, your own files in it), the IIS copy of shop and the WapForm Web Server settings are deleted as well. The license data (C:\ProgramData\WapForm\License, shared with WapForm Toolkit / Runtime) and the sales database are always kept.

4. Sample database

cd C:\Wapform\database
mysql -u root -p < sales.sql

With XAMPP the client is C:\xampp\mysql\bin\mysql.exe; you can also use phpMyAdmin > Import and choose sales.sql.

5. wapform.ini

Files: C:\Wapform\wapform.ini (shared), shop\wapform.ini (store site), flutter\lib\wapform.ini (back office). Each site folder reads its own wapform.ini. Format name=value; names are case-insensitive; save the file as UTF-8.

; ============================================================
; WapForm settings (wapform.ini)
; Required: the database settings. Everything else is optional -
; delete a line (or leave it out) to use the default shown.
; Lines starting with ; are comments.
; ============================================================

; ---- Database (required) ------------------------------------
Driver=mysql
Server=localhost
Database=sales
Username=xyz
Password=123

; ---- Optional ------------------------------------------------
; Date format on screens and reports (default: Windows regional settings)
DateFormat=yyyy/mm/dd
; Font of Windows forms and reports (default: system font, size 10).
; MingLiU covers English, Traditional Chinese and Japanese.
FontName=MingLiU
FontSize=10
; Character cell in pixels (default 7 x 13)
CharWidth=7
CharHeight=13
; Unicode (UTF-8 / utf8mb4) database connection: keep this line for
; utf8mb4 databases such as the sample; the line itself switches it on.
unicode=yes
; Interface language: en, tw or jp (default en); translations in language.txt
language=en
; LINE Messaging API - only for the LINE samples (linebot, linepush)
line_bot_id=
line_channel_secret=
line_channel_access_token=
KeySample (simulated)Meaning
drivermysqlRequired. Database type: mysql (MySQL / MariaDB); the Professional edition also supports mssql (SQL Server)
serverlocalhostRequired. Database host name or IP; use host:port for a non-default port
databasesalesRequired. Database name
usernamexyzRequired. Database account (use one limited to this database, not root)
password123Required. Database password (simulated — always change it for a real installation)
dateformatyyyy/mm/ddOptional (default: Windows regional settings). Date format on screens and reports
fontnameMingLiUOptional (default: system font). Default font of Windows forms and reports. Use a monospaced font, because layouts are measured in character cells (charwidth / charheight). MingLiU is built into Windows and covers English, Traditional Chinese and Japanese, so it fits every language (English letters are half-width, Chinese/Japanese characters full-width). For an English-only interface Consolas also works, but it has no Chinese/Japanese characters; MS Gothic (Japanese) lacks some Traditional Chinese characters.
fontsize10Optional (default 10). Default font size (points)
charwidth7Optional (default 7). Width of one character cell in pixels, used to convert WML widths given in characters
charheight13Optional (default 13). Height of one character cell in pixels, used for row heights and layout
unicodeyesOptional, but keep it for utf8mb4 databases such as the sample: the presence of the line switches Unicode on (the value is not checked); without it the connection is not Unicode. Connect and store data as Unicode (UTF-8 / utf8mb4); keep yes for new databases
languageenOptional (default en). Interface language of WapForm Toolkit / Runtime: en (English, default), tw (Traditional Chinese) or jp (Japanese). Built-in captions (navigator bar, search bar) are translated automatically; other texts come from language.txt (below)
line_bot_id(empty)Optional (LINE samples only). LINE Official Account ID (used by the linebot and linepush samples)
line_channel_secret(empty)Optional (LINE samples only). LINE Messaging API channel secret, verifies the webhook signature (X-Line-Signature)
line_channel_access_token(empty)Optional (LINE samples only). LINE channel access token for the push / reply API
loginusr / loginpwdadmin / 123Only in shop\wapform.ini: default sign-in of the store's management pages
wapform.ini holds the database password and LINE keys: never publish it on a website or commit it to GitHub. IIS does not serve .ini files by default — do not move it to a downloadable location. Get the LINE keys from the LINE Developers console and re-issue them at once if they leak.

Interface languages: language.txt

language.txt sits next to wapform.ini (UTF-8). One entry per line, English is the key, followed by the Traditional Chinese and Japanese translations separated by a comma; lines starting with ; are comments:

; English=Traditional Chinese,Japanese
Item No=料號,品番
Item Name / Spec=品名規格,品名・仕様
Search=查詢,検索

Write the labels and titles in your WML in English; with language=tw or jp they are shown translated. A missing or empty translation shows the English text. In WapForm Toolkit, Languages > Interface Languages… sets language= and edits language.txt; Add texts from last run lists every text met while running the WML, ready to translate.

The store's password-reset mail (shop\forget.wml) uses Gmail: replace your-account@gmail.com and your-gmail-app-password with your Gmail account and an app password.

6. Running the samples

Web: online store (shop)

  • IIS: http://localhost/shop/
  • WapForm Web Server (free): open WapForm Web Server from the desktop > Start, then http://localhost:8080/shop/ (documents path defaults to C:\Wapform)
  • Member sign-in: demo@example.com / 123. Category pages show 20 products per page; the recommended section lists products with active 2 or higher.

Windows: back office

  • Open the .wml pages in C:\Wapform\flutter\lib with WapForm Toolkit or Runtime, e.g. app002.wml (products) and app006.wml (shipping orders).
  • Sign in: admin / 123 (all functions) or demo / 123 (sales menu only).

Flutter: back office (Web, Android)

The project is C:\Wapform\flutter (back office in lib), the REST back end is C:\Wapform\flutter\server. The WapForm Flutter runtime is wapform_flutter on pub.dev, downloaded by flutter pub get. Complete 6-1 first, then:

cd C:\Wapform\flutter\server
npm install
node server.js                     (or run start_server.bat)

cd C:\Wapform\flutter
flutter pub get
flutter run -d chrome              (Web)

adb reverse tcp:3000 tcp:3000      (Android: forwards the phone's / emulator's localhost:3000 to this computer)
flutter run -d android             (Android)

server.js uses the same database settings as wapform.ini (sales / xyz / 123) and listens on http://localhost:3000. The Web and Android platform folders are included; there is no need to run flutter create.

WapForm for Flutter supports Web and Android. The app reaches the REST back end at http://localhost:3000; on an Android phone or emulator, localhost is the device itself, so run adb reverse tcp:3000 tcp:3000 every time a device is connected (adb comes with Android Studio, usually in %LOCALAPPDATA%\Android\Sdk\platform-tools). The sample's AndroidManifest already has the Internet permission and allows HTTP to the local back end.

6-1. Installing WapForm for Flutter (develop on Windows; targets: Web, Android)

  1. Git for Windows: git-scm.com/download/win (keep the default options).
  2. Flutter SDK: download the Windows zip from docs.flutter.dev/get-started/install/windows and extract it to a folder with no spaces or non-ASCII characters that needs no admin rights, e.g. C:\src\flutter (not C:\Program Files).
  3. PATH: Settings > System > About > Advanced system settings > Environment Variables > user variable Path > New > C:\src\flutter\bin. Open a new command prompt and check with flutter --version.
  4. Web (-d chrome): install Google Chrome.
  5. Android: install Android Studio; in SDK Manager select Android SDK, SDK Command-line Tools and Platform-Tools; create an emulator (Device Manager) or connect a phone with USB debugging enabled. Then run flutter doctor --android-licenses and accept the licenses.
  6. Node.js LTS: nodejs.org (for the REST back end).
  7. Check: run flutter doctor; Chrome and the Android toolchain should be checked (the Windows / Visual Studio items can be ignored).
  8. Editor (recommended): VS Code with the Flutter extension, or Android Studio with the Flutter plugin.

WapForm Toolkit generates Flutter .dart pages from .wml. The generated pages use the WapForm Flutter runtime wapform_flutter from pub.dev (source: github.com/wapform/wapform_flutter). After changing a .wml, generate the .dart page again and flutter run.

Release builds: flutter build web (output in build\web, can be served by IIS) and flutter build apk (output build\app\outputs\flutter-apk\app-release.apk). In production the REST back end must run on a server the phone can reach (HTTPS recommended), and the runtime's address must point to it.

7. License and trial

  • Each product starts a 30-day trial with all features on first use. After the trial, Toolkit and Runtime continue as the Free edition and WapForm for Web stops serving.
  • Buy at wapform.com/pricing; the license key is emailed to you.
  • Toolkit / Runtime: enter the key in the program's License window. WapForm for Web: open http://localhost/license.wml on the server itself and enter the key (the page opens only on the server).
  • Moving to another computer: click Deactivate on the old computer to release the seat, then activate on the new one.

8. Before going live

  • Replace every simulated value: the MySQL account (wapform.ini, server.js), the back-office account admin/123, test members, loginusr/loginpwd
  • Enter your own LINE and Gmail settings (never the sample values)
  • Delete or edit the sample products, customers and articles
  • Serve the site over HTTPS

Documentation and support: wapform.com · github.com/wapform

5. wapform.ini 參數說明

位置：C:\Wapform\wapform.ini（共用）、shop\wapform.ini（商店網站）、C:\Wapform\flutter\lib\wapform.ini（後台）。每個網站資料夾讀取自己資料夾內的 wapform.ini。格式為 名稱=值，名稱不分大小寫，檔案請存成 UTF-8。

; ============================================================
; WapForm settings (wapform.ini)
; Required: the database settings. Everything else is optional -
; delete a line (or leave it out) to use the default shown.
; Lines starting with ; are comments.
; ============================================================

; ---- Database (required) ------------------------------------
Driver=mysql
Server=localhost
Database=sales
Username=xyz
Password=123

; ---- Optional ------------------------------------------------
; Date format on screens and reports (default: Windows regional settings)
DateFormat=yyyy/mm/dd
; Font of Windows forms and reports (default: system font, size 10).
; MingLiU covers English, Traditional Chinese and Japanese.
FontName=MingLiU
FontSize=10
; Character cell in pixels (default 7 x 13)
CharWidth=7
CharHeight=13
; Unicode (UTF-8 / utf8mb4) database connection: keep this line for
; utf8mb4 databases such as the sample; the line itself switches it on.
unicode=yes
; Interface language: en, tw or jp (default en); translations in language.txt
language=en
; LINE Messaging API - only for the LINE samples (linebot, linepush)
line_bot_id=
line_channel_secret=
line_channel_access_token=
參數範例（模擬值）說明
drivermysql必填。資料庫種類。mysql（MySQL / MariaDB）；Professional 版另支援 mssql（SQL Server）
serverlocalhost必填。資料庫主機名稱或 IP；非預設連接埠時寫成 主機:埠
databasesales必填。資料庫名稱
usernamexyz必填。資料庫帳號（建議只授權這個資料庫，不要用 root）
password123必填。資料庫密碼（範例為模擬值，正式環境務必更換）
dateformatyyyy/mm/dd可省略（預設：Windows 地區設定）。畫面與報表的日期顯示格式
fontnameMingLiU可省略（預設：系統字型）。Windows 表單與報表的預設字型。請用等寬字型，因為版面以字元格（charwidth / charheight）換算。MingLiU（細明體的英文名稱，兩種寫法都可以）是 Windows 內建字型，同時涵蓋英文、繁體中文與日文，任何 language 都適用（英文半形、中日文全形）。純英文介面也可以用 Consolas，但它沒有中日文字形；MS Gothic（日文）缺部分繁體字。
fontsize10可省略（預設 10）。預設字型大小（點）
charwidth7可省略（預設 7）。一個字元格的寬度（像素），WML 以「字元數」指定欄寬時換算用
charheight13可省略（預設 13）。一個字元格的高度（像素），用於換算列高與版面
unicodeyes可省略，但 utf8mb4 資料庫（例如範例）請保留：只要有這一行就開啟 Unicode（不看值），沒有這一行就不是 Unicode 連線。以 Unicode（UTF-8 / utf8mb4）連線與存取資料；新資料庫請保持 yes
languageen可省略（預設 en）。WapForm Toolkit／Runtime 的介面語言：en（英文，預設）、tw（繁體中文）、jp（日文）。引擎內建文字（資料導覽列、查詢列）自動翻譯，其他文字由 language.txt 提供（見下方）
line_bot_id（空白）可省略（僅 LINE 範例使用）。LINE 官方帳號 ID（linebot、linepush 範例使用）
line_channel_secret（空白）可省略（僅 LINE 範例使用）。LINE Messaging API 的 Channel secret，用來驗證 webhook 簽章（X-Line-Signature）
line_channel_access_token（空白）可省略（僅 LINE 範例使用）。LINE 的 Channel access token，用來呼叫推播／回覆 API
loginusr / loginpwdadmin / 123只在 shop\wapform.ini：商店後台功能使用的預設登入
wapform.ini 含有資料庫密碼與 LINE 金鑰：不要放到公開網站、不要上傳到 GitHub。IIS 預設不會提供 .ini 下載，但請勿把它改放到可直接下載的位置。LINE 金鑰到 LINE Developers 主控台取得；外流時請立即「重新發行」。

多國語言介面：language.txt

language.txt 與 wapform.ini 放在同一個資料夾（UTF-8）。一行一筆，以英文為主要索引，等號後依序是繁體中文、日文的翻譯，以逗號分隔；; 開頭為註解：

; English=繁體中文,日本語
Item No=料號,品番
Item Name / Spec=品名規格,品名・仕様
Search=查詢,検索

WML 裡的標籤與標題用英文撰寫，language=tw 或 jp 時就會顯示翻譯；沒有翻譯或留空則顯示英文。WapForm Toolkit 的 Languages > Interface Languages… 可以設定 language= 並編輯 language.txt；Add texts from last run 會列出執行 WML 時遇到的所有文字，直接填入翻譯即可。

商店的「忘記密碼」信件（shop\forget.wml）使用 Gmail：把 your-account@gmail.com 與 your-gmail-app-password 換成你的帳號與「應用程式密碼」。

6. 執行範例

Web：線上交易平台（shop）

  • IIS：http://localhost/shop/

6-1 WapForm for Flutter 安裝（開發環境：Windows；目標平台：Web、Android）

5. wapform.ini の設定項目

場所：C:\Wapform\wapform.ini（共通）、shop\wapform.ini（ショップサイト）、C:\Wapform\flutter\lib\wapform.ini（バックオフィス）。各サイトのフォルダーは自分のフォルダー内の wapform.ini を読み込みます。形式は 名前=値、名前の大文字・小文字は区別しません。ファイルは UTF-8 で保存してください。

; ============================================================
; WapForm settings (wapform.ini)
; Required: the database settings. Everything else is optional -
; delete a line (or leave it out) to use the default shown.
; Lines starting with ; are comments.
; ============================================================

; ---- Database (required) ------------------------------------
Driver=mysql
Server=localhost
Database=sales
Username=xyz
Password=123

; ---- Optional ------------------------------------------------
; Date format on screens and reports (default: Windows regional settings)
DateFormat=yyyy/mm/dd
; Font of Windows forms and reports (default: system font, size 10).
; MingLiU covers English, Traditional Chinese and Japanese.
FontName=MingLiU
FontSize=10
; Character cell in pixels (default 7 x 13)
CharWidth=7
CharHeight=13
; Unicode (UTF-8 / utf8mb4) database connection: keep this line for
; utf8mb4 databases such as the sample; the line itself switches it on.
unicode=yes
; Interface language: en, tw or jp (default en); translations in language.txt
language=en
; LINE Messaging API - only for the LINE samples (linebot, linepush)
line_bot_id=
line_channel_secret=
line_channel_access_token=
項目例（仮の値）説明
drivermysql必須。データベースの種類。mysql（MySQL / MariaDB）。Professional 版は mssql（SQL Server）にも対応
serverlocalhost必須。データベースのホスト名または IP。既定以外のポートは ホスト:ポート
databasesales必須。データベース名
usernamexyz必須。データベースのアカウント（このデータベースだけに権限を与え、root は使わないことを推奨）
password123必須。データベースのパスワード（サンプルは仮の値。本番では必ず変更）
dateformatyyyy/mm/dd省略可（既定：Windows の地域設定）。画面と帳票の日付表示形式
fontnameMingLiU省略可（既定：システムフォント）。Windows のフォームと帳票の既定フォント。レイアウトは文字セル（charwidth / charheight）で計算するため、等幅フォントを使ってください。MingLiU（細明體）は Windows 標準のフォントで、英語・繁体字中国語・日本語をすべて含み、どの language でも使えます（英字は半角、中日文字は全角）。英語だけの画面なら Consolas も使えますが中日文字はありません。MS Gothic（日本語）は一部の繁体字がありません。
fontsize10省略可（既定 10）。既定のフォントサイズ（ポイント）
charwidth7省略可（既定 7）。文字セル 1 つの幅（ピクセル）。WML で列幅を「文字数」で指定したときの換算に使います
charheight13省略可（既定 13）。文字セル 1 つの高さ（ピクセル）。行の高さとレイアウトの換算に使います
unicodeyes省略可。ただし utf8mb4 のデータベース（サンプルなど）では残してください：この行があるだけで Unicode が有効になり（値は見ません）、行がなければ Unicode 接続になりません。Unicode（UTF-8 / utf8mb4）で接続・入出力します。新しいデータベースでは yes のままにしてください
languageen省略可（既定 en）。WapForm Toolkit／Runtime の画面の言語：en（英語、既定）、tw（繁体字中国語）、jp（日本語）。エンジン内蔵の文字（データナビゲーター、検索バー）は自動で翻訳され、それ以外は language.txt で指定します（下記参照）
line_bot_id（空欄）省略可（LINE サンプルのみ）。LINE 公式アカウントの ID（linebot、linepush サンプルで使用）
line_channel_secret（空欄）省略可（LINE サンプルのみ）。LINE Messaging API の Channel secret。webhook の署名（X-Line-Signature）の検証に使います
line_channel_access_token（空欄）省略可（LINE サンプルのみ）。LINE の Channel access token。プッシュ／応答 API の呼び出しに使います
loginusr / loginpwdadmin / 123shop\wapform.ini のみ：ショップの管理機能で使う既定のログイン
wapform.ini にはデータベースのパスワードと LINE のキーが含まれます。公開サイトに置いたり GitHub にアップロードしたりしないでください。IIS は既定で .ini をダウンロードさせませんが、直接ダウンロードできる場所に移さないでください。LINE のキーは LINE Developers コンソールで取得し、漏れた場合はすぐに「再発行」してください。

画面の多言語化：language.txt

language.txt は wapform.ini と同じフォルダーに置きます（UTF-8）。1 行に 1 項目、英語がキーで、等号の後に繁体字中国語、日本語の順にカンマで区切って翻訳を書きます。; で始まる行はコメントです：

; English=繁體中文,日本語
Item No=料號,品番
Item Name / Spec=品名規格,品名・仕様
Search=查詢,検索

WML のラベルとタイトルは英語で書いておけば、language=tw または jp のときに翻訳して表示されます。翻訳がない・空欄のときは英語のまま表示されます。WapForm Toolkit の Languages > Interface Languages… で language= の設定と language.txt の編集ができます。Add texts from last run で WML の実行中に出てきた文字が一覧になるので、そのまま翻訳を入力できます。

ショップの「パスワードを忘れた場合」のメール（shop\forget.wml）は Gmail を使います。your-account@gmail.com と your-gmail-app-password をご自身のアカウントと「アプリ パスワード」に置き換えてください。

  1. Git for Windows：git-scm.com/download/win。既定のままインストールします。
  2. Flutter SDK：docs.flutter.dev/get-started/install/windows から Windows 版の zip をダウンロードし、空白や日本語を含まない、管理者権限の不要なフォルダーに展開します。例：C:\src\flutter（C:\Program Files には置かないでください）。

WapForm Toolkit は .wml から Flutter の .dart ページを生成できます。生成されたページは pub.dev の WapForm Flutter ランタイム（wapform_flutter、ソースは github.com/wapform/wapform_flutter）を使います。.wml を変更したら .dart を生成し直し、flutter run を実行してください。
